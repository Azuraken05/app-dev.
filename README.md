# Transformers 2

**Transformers** is a live-action sci-fi action film series based on the famous toy line and animated series. It features epic battles between giant alien robots that can disguise themselves as everyday vehicles.

## The Main Factions

1. **The Autobots**: The heroic protagonists, fighting to protect humanity. 
2. **The Decepticons**: The ruthless antagonists, seeking total domination.

*My absolute favorite part of the series is the incredible CGI and the transformation sequences.*
